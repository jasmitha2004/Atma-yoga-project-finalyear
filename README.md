## 🌟 About the Project

AtmaYoga is a state-of-the-art interactive platform designed to make yoga accessible, effective, and personalized. By leveraging advanced Computer Vision and Machine Learning algorithms, AtmaYoga provides real-time feedback on user postures, ensuring safe and correct practice from the comfort of your home.

---

## ✨ Features

- **Live Pose Detection**: Real-time yoga pose recognition and correction using advanced AI and Computer Vision frameworks.
- **Personalized Recommendations**: Intelligent, mood-based and goal-oriented asana suggestions tailored just for you.
- **Interactive AI Chat Assistant**: An integrated AI yoga guide to answer your queries and formulate personalized routines.
- **Comprehensive Pose Library**: Extensive documentation covering detailed instructions, benefits, and contraindications for various poses.
- **Progress Tracking**: Sophisticated analytics to monitor your yoga journey and track your improvements over time.

## 🛠️ Technologies Used

### Frontend
- **React & Vite**: For building a lightning-fast, highly responsive user interface.
- **JavaScript & CSS3**: For dynamic interactions and modern aesthetics.

### Backend & API
- **Node.js & Express.js**: For a robust and scalable server architecture.
- **RESTful APIs**: Serving seamless data communication between client and server.

### AI & Machine Learning
- **TensorFlow & PyTorch**: Powering the core neural networks for pose classification.
- **MediaPipe & OpenCV**: For high-performance, real-time skeletal tracking and computer vision processing.

### Database
- **SQLite / MongoDB**: For flexible, secure, and reliable data storage.

## 🚀 Getting Started

Follow these steps to set up the project locally for development and testing.

### Prerequisites
Make sure you have the following installed on your machine:
- **Node.js** (v16.0.0 or higher)
- **npm** (v7.0.0 or higher)
- **Python** (v3.8 or higher) for ML components

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Gnanesh-12/AtmaYoga-Main.git
   cd AtmaYoga-Main
   ```

2. **Setup the Frontend**
   ```bash
   # Navigate to the frontend directory
   cd frontend
   
   # Install dependencies
   npm install
   
   # Start the development server
   npm run dev
   ```

3. **Setup the Backend**
   ```bash
   # Open a new terminal and navigate to the server directory
   cd server
   npm install
   npm start
   ```

*The application will typically be available at `http://localhost:5173` (Frontend) and `http://localhost:5000` (Backend).*
